The problem

Strong gym. Weak digital cohesion.

Stockholm Muay Thai already has brand, credibility and culture. The issue is not legitimacy. The issue is that the digital experience feels split across external systems, which reduces brand ownership and weakens the path from attention to membership to merch.

Current setup

Instagram as primary entry point Awareness

Good for discovery and social proof, but not enough as the full club experience.

Wondr for memberships Operations

Functional backend, but the frontend feels utilitarian. Low emotional pull. Weak premium feel.

Kappa TeamSales for merch Merch

Practical profile product setup, but it moves the user into a generic external environment.

Result: fragmented ecosystem Brand loss

A club with identity ends up feeling like a collection of links instead of a system.

Stormie Performance approach

Keep what works operationally, but rebuild the member-facing experience so the club owns the journey.

Custom website hub Front door

One place for the gym’s story, schedule, offers, intro pass, coaches and club atmosphere.

Branded membership flow Conversion

Cleaner plan selection and onboarding, even if Wondr still handles the backend.

Branded merch storefront Retention

Kappa can stay underneath, but the customer should feel Stockholm Muay Thai all the way through.

Future training layer Expansion

Optional member login, beginner path, class prep and later app/program integration.

System architecture

A full gym ecosystem, not just a website.

This is how Stormie Performance should frame the offer: not “we make websites,” but “we build digital infrastructure for fight gyms.”

01 / Website hub

A premium front layer that acts as the gym’s true home online.

  • Hero section with real training identity
  • Class schedule and intro offers
  • Coach presentation and gym culture
  • Direct paths to membership and merch

02 / Membership layer

A conversion-oriented frontend that guides the user into the right plan.

  • Intro pass / beginner trial focus
  • Beginner, unlimited, support membership structure
  • Cleaner flow before the backend handoff
  • Better emotional trust than raw software pages

03 / Merch layer

Club products presented as part of the brand, not a detached supplier page.

  • Club hoodies, tees, caps and drops
  • Better product storytelling
  • Cleaner mobile presentation
  • Kappa can remain hidden underneath if needed
Operational clarity

Schedule and membership made simple.

The user should not need to decode multiple systems. Core information should live in one premium surface, with clear next actions.
