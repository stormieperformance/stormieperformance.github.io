How it works
The integration problem between strength and sport.
After analysis, the engine generates
  • PCI (global) + sub-scores (Lower/Hinge/Pull)
  • Aggressive imbalance detection + focus directive
  • Strength frequency (sessions/week)
  • Intensity limit (RPE cap)
  • Back-off volume adjustment
  • Weekly integrated plan (Mon–Sun)
  • Accessories + recovery directive
  • Overreach Index (0–100) + status

  • Progression layer (history + trends)
  • Weekly templates per goal (strength / performance / aesthetics)
  • Imbalance warnings by sport mode
Definitions

Total sessions = all sessions (easy + moderate + hard).

High-intensity sessions = subset inside total (sparring/limit bouldering etc.). Example: total 5, high-intensity 2.

Representative set = a hard clean set you could repeat next week (not a 1RM test).

PCI = weighted capacity composite (hybrid-first) with strict imbalance sensitivity.

Overreach Index = sport stress + effort + fatigue ± tolerance modifiers.

RPE = effort rating (10 = max, 8 ≈ ~2 reps in reserve).
